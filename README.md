# 🐕 柴犬カフェ繁盛記

柴犬カフェを経営するブラウザゲームです。かわいい柴犬たちでお客さんを笑顔にして、お店を繁盛させましょう。

## 遊び方(起動)

`index.html` をブラウザで開くだけで遊べます。インストールやサーバーは不要です。
画像はすべてHTMLに埋め込み済みなので、このファイル1つあれば動きます。

- セーブはブラウザ(localStorage)に保存されます。💾 セーブボタンのほか、毎日の営業終了時にも自動保存されます
- ゲーム内の「❓ 遊び方」ボタンでも操作説明を確認できます
- **スマホ対応**: 画面幅700px以下ではフロアが上・操作パネルが下の縦積みレイアウトに切り替わり、縦持ちで遊べます。なおスマホのGoogleドライブアプリのプレビューではJavaScriptが動かないため、HTMLをスマホにダウンロードしてブラウザで開くか、GitHub Pagesなどにホストしてください

## ゲームの目的

最終目標は **柴犬図鑑 全30種(毛色5種 × 性格6種)のコンプリート** です。
お客さんを満足させてお金と評判を稼ぎ、店舗を拡張し、たくさんの柴犬をスカウトしましょう。

## 1日の流れ

- 1日は約60秒。画面上部のバーが満タンになると営業終了です
- ヘッダーの ⏸️ ボタンでいつでも一時停止できます(停止中はお世話などの操作もできません)
- 営業終了時に売上のまとめと **餌代の精算** があります。スカウト・おやつ・しつけ・店舗拡張・譲渡のお礼など、その日のお金の動きはすべて項目別に表示され、差引に反映されます
  - 餌代は **1頭につき30G/日(豆柴は小食なので20G)**
  - **餌代が払えないと破産 = ゲームオーバー**。セーブは消えますが、図鑑の記録だけは引き継いで再スタートできます
- 朝の時点で所持金が餌代を下回っていると警告が出ます。計画的に!

## 柴犬のお世話

フロアの柴犬、またはサイドパネルのカードをクリックするとお世話メニューが開きます。

| 操作 | 費用 | 効果 |
|---|---|---|
| 🪮 ブラッシング | 無料 | 換毛ゲージをリセット。ゲージが30以上の時は機嫌+10(連打しても機嫌は上がらない) |
| 🦴 おやつ | 50G | 機嫌+30。拒否柴モードも解除 |
| 🎓 しつけ | 200G×Lv | レベルアップ。収入アップ&問題行動が減る(最大Lv5) |

- **ご機嫌は自動では回復しません。** 放っておくと下がる一方で、収入もふれあい効果も落ちます
- 換毛ゲージがたまると抜け毛が舞ってお店が汚れます。こまめにブラッシングを
- 清潔度が下がると客足と会計額が減ります。🧹 そうじ(無料)で回復しましょう

## ふれあいシステム

柴犬はときどきお客さんに自分から近寄っていきます(💞マーク)。
ふれあい中はお客さんの **満足度** がぐんぐん上がり、満足度はそのまま **会計額(30G+満足度)と評判** に直結します。

- 機嫌が良い柴犬・レベルが高い柴犬ほど効果大
- スマイル柴・甘えん坊は、ふれあいがさらに得意

## スカウトと図鑑

- 🎁 スカウト(500G)で新しい柴犬をお迎え。毛色・性格・レア度(★1〜4)はランダムです
- **図鑑に新しい組み合わせが登録されると+300G** のボーナス
- 柴犬スペースが満員だとスカウトできません。店舗拡張するか、譲り受けの申し出を待ちましょう

### 毛色(5種)

赤柴 / 黒柴 / 白柴 / 胡麻柴 / 豆柴

### 性格(6種)

| 性格 | 特徴 |
|---|---|
| 甘えん坊 | お客さんにべったり。ふれあい収入 +30% |
| スマイル柴 | 天性の笑顔。お客さんの満足度が上がりやすい |
| 柴ドリル | 突然ブルブルッ!店は汚れるがお客さんは大喜び |
| 拒否柴 | テコでも動かない。だがその姿がSNSでバズって評判UP |
| ツンデレ | 機嫌の波が激しい。デレ期に入ると収入2倍 |
| ヘソ天 | 無防備にお腹を見せて爆睡。撮影会が始まり大きな収入に |

## 柴犬の譲り受けイベント

大満足したお客さんが帰り際に「この子を家族に迎えたい」と申し出ることがあります(1日1回まで)。

- **譲る**: お礼のお金(レア度・レベル・満足度に応じて増額)と評判+3。スペースに空きができ、新しい子をスカウトできます。**図鑑の登録は消えません**
- **断る**: ペナルティなし。うちの子はうちの子!

図鑑コンプを目指すなら、譲り受けをうまく使って柴犬を入れ替えていくのがポイントです。

## 店舗拡張

| 項目 | 初期 | 効果 |
|---|---|---|
| 🪑 客席 | 3席 | +1席。同時に入れるお客さんが増える |
| 🐕 柴犬スペース | 2頭 | +1頭。飼える柴犬が増える |

拡張費用は買うたびに約1.6倍ずつ高くなります。
